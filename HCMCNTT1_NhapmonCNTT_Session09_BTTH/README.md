# 🎓 SmartCampus

![Logo dự án SmartCampus](https://placehold.co/200x200/png?text=SmartCampus "Logo SmartCampus")

**SmartCampus** là ứng dụng di động giúp sinh viên PTIT *tra cứu* lịch học, phòng trống và nhận thông báo mới nhất từ nhà trường.

## Tính năng đã hoàn thành

- Tra cứu lịch học theo mã sinh viên
  - Nhập mã sinh viên để xem lịch học
- Xem danh sách phòng trống theo tòa nhà
  - Chọn tòa nhà để xem phòng trống

Trang chủ CLB: [CLB Lập trình PTIT](https://clblaptrinh.ptit.edu.vn)

> ⚠️ **Cảnh báo:** Dự án đang trong giai đoạn phát triển, chưa dùng cho mục đích chính thức.

---

## :rocket: Cài đặt

```bash
git clone https://github.com/clb-lap-trinh/smartcampus.git
npm install
npm start
```
