# API là gì?

## 1. Hiểu nhanh bằng ví dụ nhà hàng 🍽️

Bạn ngồi ở bàn, bếp ở phía sau. Bạn **không vào bếp**, mà gọi món qua **người phục vụ**.

- Bạn là **ứng dụng** (ví dụ SmartCampus)
- Bếp là **máy chủ** (nơi lưu dữ liệu lịch học)
- Người phục vụ là **API**

**API là người trung gian** nhận yêu cầu của ứng dụng, chuyển cho máy chủ, rồi mang kết quả về.

## 2. API trong SmartCampus

1. Sinh viên nhập **mã sinh viên** trên ứng dụng
2. Ứng dụng gửi **yêu cầu** qua API
3. Máy chủ tìm lịch học và **trả kết quả** về
4. Ứng dụng hiển thị lịch học lên màn hình

## 3. Vì sao cần API?

- Ứng dụng **không cần biết** dữ liệu được lưu thế nào
- Dữ liệu **an toàn hơn**, vì không ai vào thẳng "bếp"
- Nhiều ứng dụng có thể **dùng chung** một nguồn dữ liệu

## 4. Ghi nhớ

> **API = người phục vụ giữa ứng dụng và máy chủ.**
